    Smart Campus Navigation System

    A PBL project that turns a console-based C++ program into a modern web application. The website sends the selected locations to a C++ REST API, which runs Dijkstra's Shortest Path Algorithm on the campus graph and returns the best route.

    Architecture

    • FrontendHTML · CSS · JavaScript
    • ⇄ REST (JSON)
    • BackendC++17 · Crow framework
    • ↓
    • AlgorithmDijkstra on an adjacency matrix

    REST API Endpoints

    GET/api/healthServer status
    GET/api/locationsAll locations & connections
    POST/api/routeShortest route between two locations

    How to use

    1. Pick a starting location and destination (or click markers on the map).
    2. Press Find Shortest Route.
    3. Read the route, distance and highlighted path on the map.
    4. Press Reset to start again.
